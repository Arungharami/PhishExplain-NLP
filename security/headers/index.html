Email header analyzer

Follow the route. Question the claims.

Paste the full original headers (in Gmail: ⋮ → Show original; in Outlook: File → Properties → Internet headers). Shield parses the route and authentication claims locally.

Trust boundary: SPF, DKIM and DMARC results in pasted headers are unverified claims. Anyone can write or edit these headers. Shield does not perform authentication checks and never reports them as verified.
