Settings & privacy

You decide what is kept.

Shield works without an account and keeps nothing by default. These settings apply only to this browser.

Local scan history

When enabled, each scan you choose to save is stored in this browser's local storage (not encrypted by Shield, not synced, not sent anywhere). Saved reports include sender addresses, subjects, URLs and short evidence excerpts — not the full message.

Shield access key

Optional reputation and AI checks are protected by an access key issued by the deployment owner. The key is kept in this tab's session storage only and is cleared when the tab closes. It is never included in reports.

Service status

Reported live by this deployment. Unavailable services never block the local scanner.

Privacy summary

  • The scanner parses messages in your browser. Message content is not uploaded.
  • Reputation checks send only the selected URLs, and only after you consent.
  • AI analysis sends the message text to the model provider, and only after you consent.
  • The server logs operational metadata (counts, latency, token usage) — never message text or URLs.
  • No analytics, advertising trackers or third-party fonts are loaded.
  • Use synthetic or your own messages. Do not submit other people's private email unless you are authorized.
