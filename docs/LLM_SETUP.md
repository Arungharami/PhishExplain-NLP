## Researcher-only transformer setup

The Vercel endpoint /api/infer is implemented but cannot produce genuine model results without credentials. In the existing phishexplain-nlp project, set server-only production environment variables OPENAI_API_KEY and PHISHEXPLAIN_RESEARCH_KEY (a separate long random password); optionally set OPENAI_MODEL. Redeploy production. Enter the separate researcher key into the live lab (it stays in browser memory, not localStorage). Never paste actual secrets into the repository or chat. The endpoint rejects unauthenticated requests; do not enable public unrestricted API usage. No live experiment results are asserted until an actual provider run succeeds. Input email text is sent to the chosen model provider and should be public or synthetic only. The endpoint does not follow URLs and validates grounding. A transformer model's output is not human-reviewed gold. For broader deployment add provider cost controls, durable rate limits and monitoring. Verify that the chosen model supports JSON object mode and the configured sampling parameters.
