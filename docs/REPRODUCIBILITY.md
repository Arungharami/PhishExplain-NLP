# Reproducibility

Source data: data/candidate_emails.json. Split: data/split_manifest.json, frozen by numeric ID modulo 3. Annotation output: exported manually from /annotation/, with reviewer, rationale, label spans and original text. Baseline: engine.js deterministic lexical extractor. Transformer: api/infer.js server-only prompted provider integration; record provider, exact model, prompt_version, request timestamp and output; credentials never committed. Every label and output must pass lib/spans.js validateSpans. Use scripts/evaluate.mjs with a frozen fully reviewed JSON containing the test examples and both true method outputs. Compute precision, recall and micro/macro exact-match F1 on the same 40 held-out test records. Evaluate errors per example. Keep raw run artifacts and a manifest with data/prompt/model versions and hashes. Never change the test data or gold after final scoring. This repository does not presently include verified comparative results.
